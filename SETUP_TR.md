# VS Code ile Kurulum — Sonraki Aşama

1. ZIP dosyasını bir klasöre çıkarın.
2. VS Code > File > Open Folder ile `mini_catalog_project` klasörünü açın.
3. Terminal > New Terminal açın.
4. `flutter doctor` çalıştırın; eksikleri tamamlayın.
5. `flutter create --platforms=android,ios .` komutunu çalıştırın. (Native proje klasörlerini oluşturur.)
6. `flutter pub get` komutunu çalıştırın.
7. Android Studio'da emülatörü başlatın veya Android cihazınızı bağlayın.
8. `flutter devices` ardından `flutter run` komutlarını çalıştırın.
9. `flutter test` ve `flutter analyze` ile kontrol edin.
10. Gerçek ekran görüntülerini `screenshots/` klasörüne kaydedin.

Not: iOS uygulamasını derlemek için macOS ve Xcode gerekir. Windows'ta Android üzerinde çalıştırabilirsiniz.
